# Machine Learning Workflow – Student Performance Dataset

## Dataset Chosen
**Student Performance Dataset**

## Problem
The goal is to predict whether a student will **Pass or Fail** using their study-related information.

## ML Type
**Supervised Learning – Classification**

The model learns from old student data where the result is already known.

## Features
- Study Hours
- Attendance
- Previous Marks
- Assignment Performance

## Target
**Result → Pass / Fail**

## Machine Learning Workflow

### 1. Define the Problem
Predict whether a student will pass or fail.

### 2. Get the Data
Use a Student Performance Dataset containing student details and results.

### 3. Explore the Data
Check the rows, columns, missing values, and understand the data.

### 4. Clean the Data
Fix missing values, wrong data, and remove unnecessary data.

### 5. Split the Data
Divide the data into:
- Training Data – 80%
- Testing Data – 20%

### 6. Train the Model
Use a classification algorithm to train the model.

### 7. Evaluate the Model
Check how accurately the model predicts the result.

### 8. Tune the Model
Try different settings to improve the model.

### 9. Deploy the Model
Use the trained model in a real application or website.

### 10. Monitor the Model
Check whether the model is still working properly and update it when needed.
